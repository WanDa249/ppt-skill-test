# AI-PPT-Skill Context for AI Agents

## Project Identity

AI-PPT-Skill is a reusable skill that enables general AI agents to follow a professional presentation creation workflow.

It is not a PPT application. It provides reasoning frameworks, workflows, and decision controls.

## Current Stage

Prototype validation stage.

The priority is proving the minimum effective structure, not expanding into a large autonomous system.

## Current Principles

1. Keep the project as a Skill, not a standalone platform.
2. Preserve human decision ownership at important checkpoints.
3. Validate new mechanisms before making them core.
4. Use references as visual guidance, not templates.
5. Prefer simple effective mechanisms over complex infrastructure.

## Avoid Continuing These Directions Without New Evidence

- Large design knowledge base
- RAG-driven design retrieval platform
- Autonomous presentation system
- Heavy runtime orchestration
- Template marketplace

Historical exploration of these topics exists in docs/HISTORY and docs/ARCHIVE.

## How to Continue Work

Before adding a mechanism:

1. Identify the real failure it solves.
2. Check whether existing workflow already solves it.
3. Run a validation experiment if uncertain.
4. Record architectural changes through ADR.
