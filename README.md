# AI-PPT-Skill Test Repository

This repository is a minimal release-style test package for AI-PPT-Skill.

It contains only the information required for a new AI agent to understand and apply the Skill.

## Purpose

Test whether an AI can correctly understand:

- the Skill boundary;
- the professional workflow;
- user decision points;
- visual direction process.

Historical design records and experiments are intentionally excluded.
